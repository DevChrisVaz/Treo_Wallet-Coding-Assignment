# TreoWallet móvil

App móvil de TreoWallet (Expo + React Native + Expo Router, TypeScript estricto). Especificación en `openspec/changes/mobile-app/`.

```bash
npm install
npm start          # Expo Go o simulador
npm run lint       # ESLint
npm run typecheck  # tsc --noEmit
npm run format:check
npm test           # jest-expo
```
